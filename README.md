# Oketa Arquitetura — site institucional

Projeto técnico de uma página institucional para um escritório de arquitetura do Litoral Norte de São Paulo.

## Problema

Um escritório de arquitetura precisa apresentar sua linguagem visual, serviços e projetos sem perder clareza em telas pequenas. Esta página reúne essas informações em uma navegação única e responsiva.

## Funcionalidades

- Hero com chamadas para conhecer projetos e solicitar contato.
- Seções institucionais, serviços, galeria e projetos.
- Depoimentos, perguntas frequentes e formulário de contato no layout.
- Menu adaptado para dispositivos móveis.
- Rolagem suave e animações de entrada.
- Metadados básicos de SEO.

## Tecnologias

- HTML5.
- CSS com variáveis e media queries.
- JavaScript incorporado ao documento.
- Google Fonts e imagens do Unsplash.

O projeto está concentrado em um único arquivo: `oketa_arquitetura_camburi (1).html`.

## Como executar

```bash
git clone https://github.com/Augustodevv/site-oketa.git
cd site-oketa
```

Abra `oketa_arquitetura_camburi (1).html` no navegador.

## Estado do projeto

Projeto de portfólio em desenvolvimento. Imagens, estatísticas, depoimentos, links e dados de contato presentes no layout são demonstrativos; esse conteúdo deve ser validado antes de qualquer publicação comercial.
